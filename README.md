# Smart Medicine Reminder Box Using 8051

## Project overview
The Smart Medicine Reminder Box is an 8051-based project designed to remind users when it is time to take medicine. The reminder is shown on an LCD and indicated with an alert. The circuit and program are demonstrated using EWSIM.

## Objectives
- Design a medicine reminder system using an 8051 microcontroller.
- Simulate the circuit and program in EWSIM.
- Provide a visual and audio reminder when medicine is due.

## Main components
- 8051 microcontroller
- LCD
- DS1307 real-time clock
- LED
- Push button
- Speaker or buzzer

## Project files
- `8051-1.c` — 8051 program source code
- `circuit.sim2` — EWSIM circuit file
- `project.json` — EWSIM project settings
- `circuit project.png` — circuit screenshot
- `circuit-project.zip` — ZIP archive of the project

## Software
- EWSIM — circuit design and simulation

## How to view the project
Download or clone this repository, then open `circuit.sim2` in EWSIM to view the circuit. The source code is in `8051-1.c`.

## Current limitation
The simulation runs with its configured reminder timing, but the timing cannot currently be changed through the project.

## Note
This repository contains a simulated project. The circuit screenshot and project files are included for review.
